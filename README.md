# Deutsch A1.1

Личный тренажёр из семи лекций. Темы сверены с оглавлением и грамматическими разворотами учебника из папки `Book`. Объяснения, примеры, карточки и упражнения для сайта редактируются в `course.js`.

## Открыть

Откройте `index.html` в браузере. Установка и сборка не требуются. Для надёжного сохранения прогресса используйте сайт по HTTP(S), например на GitHub Pages. Прогресс хранится в браузере для конкретного адреса сайта.

## Опубликовать на GitHub Pages

1. Загрузите `index.html`, `style.css`, `course.js`, `app.js` и `.nojekyll` в корень репозитория на GitHub. Папка `Book` нужна только как источник для подготовки материалов.
2. В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` (или вашу основную ветку) и папку `/ (root)`.
3. Нажмите **Save**. После публикации адрес появится здесь же.

Все ссылки на ресурсы относительные, поэтому сайт работает и на адресе проекта вида `username.github.io/repository/`.

## Прогресс

Каждая лекция содержит три отслеживаемых раздела. Отметьте теорию прочитанной, вспомните каждую карточку хотя бы один раз и решите все упражнения за один подход. Рядом с итоговой вкладкой показан лучший результат теста.

После открытия перевода выберите «Снова», «Трудно», «Хорошо» или «Легко». Под каждой оценкой указан срок следующего повтора. Для новой карточки это 1 минута, 10 минут, 1 день и 4 дня соответственно. После успешных повторений интервалы растут. Оценка «Снова» возвращает карточку через минуту и запускает интервалы заново. Свободное повторение всех слов сохраняет расписание прежним.

При редактировании программы сохраняйте идентификаторы лекций и порядок уже изучаемых слов, пока соответствующий прогресс нужен. Позиция слова внутри лекции служит идентификатором карточки.

При переходе с первой версии курса расписание карточек с совпадающими словами переносится автоматически. Для новых лекций, упражнений и итогового теста прогресс считается заново.

## Резервная копия

На главной раскройте «Резервная копия прогресса» и нажмите «Скачать копию». Сохраните файл JSON у себя. Для переноса откройте курс в нужном браузере, выберите этот файл и подтвердите замену прогресса. Если учились в обоих браузерах, сначала скачайте копию в каждом.

## Озвучка

Кнопка «Слушать» использует синтез речи браузера. Если доступен швейцарский немецкий голос, сайт выбирает его первым. Иначе используется доступный немецкий голос.
